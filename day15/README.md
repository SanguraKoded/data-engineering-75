/*
DAY 15 — CTEs AND SUBQUERIES

A CTE is a named temporary result set created using WITH.
It exists for the duration of the SQL statement.

A recursive CTE can reference itself to generate
sequential results or process hierarchical data.

A subquery is a query nested inside another SQL query.

A correlated subquery references columns from the outer query.

A temporary table is a database object that can be
reused across multiple statements within its lifetime.

I would use CTEs to break complex SQL queries into
readable, logical stages.
*/
